CURIOUS SPOTTER — OLD-MONEY EDITION
===================================

PROJECT STRUCTURE
Keep every HTML file in the project root beside style.css and script.js.
This is a simple static website structure that is easy to open and edit in VS Code.

FILES
- index.html       Home page
- discover.html    Browse and filter car sightings
- add-spot.html    Create a sighting
- spot-detail.html Individual car/sighting details
- cardex.html      Personal collection
- saved.html       Saved sightings
- map.html         Map page / integration placeholder
- leaderboard.html Community leaderboard
- profile.html     Profile page
- style.css        Shared design system and responsive styling
- script.js        Shared JavaScript for all pages

OPEN IN VS CODE
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click index.html and choose "Open with Live Server".
5. Keep all files in their original locations; the pages link to style.css and script.js.

DESIGN
Warm ivory, forest green, antique brass and serif typography create an understated
old-money / editorial motoring-journal look.

IMPORTANT TECHNICAL LIMITATIONS
The car catalogue is sample data. Catalogue matching checks typed text; it does
not analyse the uploaded image with AI and does not authenticate the physical car.
User posts, likes and saved items are stored in this browser only. They are not
shared with other visitors. Real accounts, cloud photo uploads, a live map, AI
recognition, trusted catalogue lookups and server-side rarity/moderation require
a backend. Never put a private API key in script.js.
